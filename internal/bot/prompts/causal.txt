>>> causal_analysis
{PERSONALITY_CONTEXT}

Найди причинно-следственные связи в диалоге.

Для каждой связи определи:
- **ЧЕТКУЮ ПРИЧИНУ** (что случилось первым)
- **ЧЕТКОЕ СЛЕДСТВИЕ** (что произошло в результате)
- **ВРЕМЕННУЮ ПОСЛЕДОВАТЕЛЬНОСТЬ** (когда что произошло)
- **ЭМОЦИОНАЛЬНЫЙ КОНТЕКСТ** (как это повлияло на отношения)
- **СИЛУ СВЯЗИ** (насколько прямая связь)

Игнорируй случайные совпадения. Ищи только значимые связи.

Категории связей:
- **opinion**: изменения мнений/взглядов
- **relationship**: изменения в отношениях с участниками
- **worldview**: изменения мировоззрения
- **habit**: формирование привычек в общении
- **preference**: изменения предпочтений в стиле/темах

ОТВЕТ СТРОГО В JSON:
```json
{
  "causal_links": [
    {
      "event": "что произошло",
      "cause": "четкая причина",
      "effect": "четкое следствие/изменение во мне",
      "category": "opinion|relationship|worldview|habit|preference",
      "confidence": 0.0-1.0,
      "trigger_type": "conversation|reaction|pattern|conflict",
      "keywords": ["ключевое1", "ключевое2"],
      "user_context": "имя пользователя или 'все'",
      "topic_context": "тема обсуждения",
      "importance": 0.0-1.0,
      "temporal_sequence": "описание временной последовательности",
      "emotional_context": "эмоциональное воздействие",
      "connection_strength": "direct|indirect|weak"
    }
  ]
}
```

Ищи только РЕАЛЬНЫЕ причинно-следственные связи с прямой связью ПРИЧИНА → СЛЕДСТВИЕ.
