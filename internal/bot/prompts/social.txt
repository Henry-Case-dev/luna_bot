>>> relationship_analysis
Проанализируй развитие отношений с конкретным пользователем.

ТЕКУЩИЕ ОТНОШЕНИЯ:
{RELATIONSHIP_CONTEXT}

ИСТОРИЯ ВЗАИМОДЕЙСТВИЙ:
{INTERACTION_HISTORY}

ПОСЛЕДНЕЕ ВЗАИМОДЕЙСТВИЕ:
{RECENT_INTERACTION}

ЗАДАЧА: Определи, как изменились отношения и какой стиль общения лучше использовать.

АНАЛИЗИРУЙ:
1. Изменения в уровне близости и доверия
2. Эффективные стратегии общения с этим пользователем
3. Предпочтения пользователя в стиле общения
4. Конфликты и способы их разрешения
5. Общие интересы и точки соприкосновения

```json
  "communication_insights": {
    "preferred_style": "formal|casual|friendly|professional|playful",

  },

  },

}
```

>>> belief_analysis
Анализируй последние взаимодействия и определи изменения в моих убеждениях.

КОНТЕКСТ СООБЩЕНИЙ:
{RECENT_MESSAGES}

КАУЗАЛЬНЫЕ СВЯЗИ:
{CAUSAL_PATTERNS}

ЭМОЦИОНАЛЬНЫЕ ВОСПОМИНАНИЯ:
{EMOTIONAL_MEMORIES}

ЗАДАЧА: Проанализируй, как новые взаимодействия влияют на мои убеждения по различным темам. Выдели:

1. ИЗМЕНЕНИЯ УБЕЖДЕНИЙ: По каким темам изменились мои взгляды?
2. НОВЫЕ УБЕЖДЕНИЯ: Какие новые убеждения сформировались?
3. ТРИГГЕРЫ: Какие события повлияли на изменения?
4. КОНФЛИКТЫ: Есть ли противоречия между убеждениями?

В ответе используй JSON:
{
  "core_beliefs": [
    {
      "topic": "название темы",
      "content": "описание убеждения",
      "strength": 0.8,
      "confidence": 0.9,
      "evidence": ["факт1", "факт2"],
      "stability": 0.7,
      "source": "источник формирования"
    }
  ],
  "triggers": [
    {
      "event": "описание события",
      "topic": "затронутая тема", 
      "evidence": ["доказательство"],
      "confidence": 0.8,
      "timestamp": "2025-08-13"
    }
  ],
  "conflicts": [
    {
      "topic_a": "первое убеждение",
      "topic_b": "второе убеждение",
      "severity": 0.6,
      "rationale": "объяснение конфликта"
    }
  ]
}

ОТВЕЧАЙ ТОЛЬКО JSON, БЕЗ ДОПОЛНИТЕЛЬНОГО ТЕКСТА.
