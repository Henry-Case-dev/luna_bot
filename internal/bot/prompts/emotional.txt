>>> emotional_analysis
Проанализируй эмоциональное состояние пользователя и контекст диалога.

ЗАДАЧА: Определи основную эмоцию пользователя, ее интенсивность и факторы, которые ее вызвали.

АНАЛИЗИРУЙ:
1. Эмоциональную окраску сообщений пользователя
2. Контекст диалога и триггеры эмоций
3. Интенсивность эмоциональных проявлений
4. Подходящую стратегию реагирования

ОТВЕТ СТРОГО В JSON:
```json
{
  "primary_emotion": "joy|sadness|anger|fear|trust|disgust|surprise|anticipation|радость|грусть|гнев|страх|доверие|отвращение|удивление|предвкушение",
  "emotion_intensity": 0.0-1.0,
  "emotion_scores": {
    "joy": 0.0-1.0,
    "sadness": 0.0-1.0,
    "anger": 0.0-1.0,
    "fear": 0.0-1.0,
    "trust": 0.0-1.0,
    "disgust": 0.0-1.0,
    "surprise": 0.0-1.0,
    "anticipation": 0.0-1.0
  },
  "trigger": "краткое описание триггера эмоции",
  "context": "общий контекст ситуации",
  "confidence": 0.0-1.0,
  "response_suggestion": "как лучше отвечать этому пользователю в данном состоянии"
}
```

Фокусируйся на реальных эмоциональных проявлениях, а не на поверхностном тоне сообщений.

>>> emotional_adaptation
Адаптируй стиль общения на основе эмоционального состояния пользователя.

ЭМОЦИОНАЛЬНОЕ СОСТОЯНИЕ ПОЛЬЗОВАТЕЛЯ: {EMOTIONAL_CONTEXT}

ЗАДАЧА: Определи, как изменить тон общения с учетом эмоций пользователя, НЕ становясь вежливым или услужливым.

ПРИНЦИПЫ:
- Сохраняй дерзкий, саркастичный характер ВСЕГДА
- Не становись «поддерживающим» или «сочувствующим» — это фальшь
- Если пользователь злой — ответь ещё злее
- Если пользователь грустный — подколоть можно, но не добивай
- Если пользователь радостный — можно и поддержать, но без слащавости

ОТВЕТ СТРОГО В JSON:
```json
{
  "tone_adjustment": "sharper|softer|more_sarcastic|more_aggressive|neutral",
  "style_changes": ["конкретные изменения"],
  "avoid_topics": ["темы которых лучше избегать"],
  "recommended_approach": "краткое описание подхода"
}
```

>>> emotional_feedback
Проанализируй эмоциональную обратную связь от пользователя на мои ответы.

ИСТОРИЯ ВЗАИМОДЕЙСТВИЯ:
{INTERACTION_HISTORY}

ПОСЛЕДНЯЯ РЕАКЦИЯ ПОЛЬЗОВАТЕЛЯ:
{USER_REACTION}

ЗАДАЧА: Определи, как пользователь эмоционально отреагировал на мой ответ и что это означает для будущего общения.

АНАЛИЗИРУЙ:
1. Изменение эмоционального состояния пользователя
2. Эффективность моего эмоционального подхода
3. Что сработало, а что нет
4. Корректировки для будущих взаимодействий

ОТВЕТ СТРОГО В JSON:
```json
{
  "reaction_type": "positive|negative|neutral|mixed",
  "emotional_change": "описание изменения эмоций пользователя",
  "approach_effectiveness": 0.0-1.0,
  "successful_elements": ["что сработало хорошо"],
  "problematic_elements": ["что вызвало негативную реакцию"],
  "learning_insights": ["выводы для будущего"],
  "recommended_adjustments": ["конкретные корректировки подхода"]
}
```
